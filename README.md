# Employee Raise Issue – ServiceNow

## Overview

This project implements an Employee Raise Issue system using ServiceNow.

The solution allows employees to submit workplace-related issues through a customized Employee Center Service Portal. Submitted issues are stored as employee issue records for tracking and management.

## Key Features

- Custom ServiceNow application
- Custom Employee Raise Issue table
- Custom fields and dependencies
- UI Policies
- Record Producer for submitting employee issues
- Employee Center Service Portal
- Custom Commercial Services widget
- Custom HTML and CSS styling
- Issue submission and ticket creation
- Attachment support
- Employee-friendly portal interface

## Workflow

Employee Center Portal
        ↓
Raise an Issue
        ↓
Raise Employee Issue
        ↓
Enter Issue Details
        ↓
Submit
        ↓
Employee Ticket Created
        ↓
Ticket Number Generated
